# [WO-018] Validate real traffic and release the first personal beta

<!-- wallet-observer-task:WO-018 -->

**Milestone:** First live

**Plan:** [BUILD_PLAN.md](https://github.com/nhattruong0204/wallet-observer/blob/main/BUILD_PLAN.md)

## Why we need this

The first-live milestone should be based on observed operation and correctness, not only a successful build or a screenshot.

## What to do

- Run the deployed tool with 10–25 selected wallets and publish a concise acceptance report.
- Release a tagged first beta after the launch gate passes; keep unsupported features visibly disabled.

## How to implement

1. Observe at least 24 hours of operation, extending the interval if insufficient representative activity occurs. Record event counts, source coverage, errors, lag, and provider usage.
2. Verify a sample of supported buys/sells against source transactions. Use recorded fixtures for edge cases not observed during the trial.
3. Exercise source disconnect, worker restart, browser reconnect, provider throttling, quote outage, duplicate delivery, and backup restore.
4. Confirm private access and inspect frontend artifacts/logs for accidental credentials. Review notification volume with the user.
5. Document limitations and remaining defects; do not mark partial-history positions, FOMO metadata, or unsupported routes complete.
