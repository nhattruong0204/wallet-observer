**Milestone:** First live

## Why we need this

An alert becomes useful when you can immediately see the observed wallet/token history and the limits of the available evidence.

## What to do

- Build wallet detail and token detail using the shared read contracts.
- Show filtered trade history, available quote fields, exact identities, and source links.

## How to implement

1. Add wallet-to-token and token-to-wallet navigation while keeping the selected filters and chain context.
2. Display observed buy/sell totals only from eligible executions. Show sample start, last update, missing USD values, and coverage gaps.
3. Use wallet aliases as labels and preserve full addresses. Keep FOMO identity fields absent until their evidence-bearing integration exists.
4. Load expensive histories incrementally and reuse quote/cache state without silently substituting latest prices for execution prices.
