## Why we need this

FOMO account and thesis context is valuable only when source identities and token references remain attributable and up to date.

## What to do

- Implement the verified identity and thesis capabilities from the source qualification gate.
- Extend profile/token/search views with FOMO-specific evidence, without restoring excluded social platforms.

## How to implement

1. Use immutable source user IDs, mutable aliases, and evidence-bearing wallet links. Keep manual labels distinguishable from source-confirmed identity.
2. Persist thesis IDs, text, edits/deletions where supported, token mentions, timestamps, and provenance.
3. Validate token mentions by chain/address. Distinguish commentary from an actual buy; do not infer a purchase from a thesis.
4. Process thesis revisions through canonical updates and source checkpoint recovery. Use bounded retention and a stated collection start.
5. Show grouped author commentary and optional on-demand cached translation only after its provider and budget are explicitly configured.

## Definition of done

- [ ] Account rename preserves history and correct wallet links.
- [ ] Two similar names never merge without evidence.
- [ ] Theses appear on the appropriate token/profile pages with source/time labels.
- [ ] A thesis without an execution cannot create a buy or position.
- [ ] Unsupported edits/deletions and historical gaps are declared.
- [ ] If source access is absent, the feature remains disabled and this issue is blocked rather than falsely completed.
