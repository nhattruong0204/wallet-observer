**Milestone:** Personal expansion

## Why we need this

Stored trade history can show concentration of activity without paying for a separate global ranking product.

## What to do

- Add local token heat, unique-buyer/seller boards, directional volumes, net flow, and mover history.
- Provide 24h/7d/30d windows only where collection/retention supports them.

## How to implement

1. Write metric definitions with event eligibility, USD-price coverage, window boundaries, and distinct-wallet/person semantics.
2. Start with indexed SQL and bounded materialized rollups only if measurement requires them; no separate analytics database.
3. Keep any heat formula transparent and versioned. Do not present a proposed formula as Wind's unpublished score.
4. Allow drill-down from each score or mover to its source executions and participant list.
5. For incomplete windows, show partial coverage. Add FOMO-thesis counts only after the thesis adapter exists.
