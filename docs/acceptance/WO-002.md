The operator's wall clock was not independently calibrated, and request capture
timestamps are not perfectly monotonic. Use the monotonic stream durations and
slot bounds for the experiment. The single delay value is a raw observation with
block-time granularity/clock uncertainty, not a performance guarantee.

Both runs first requested up to two 100-record pages per address. Address 1
returned 200 records and remained truncated; address 2 returned 27 and then an
empty terminal page. Recovery requests used a separate bounded slot range and
fully exhausted pagination. Do not confuse the truncated historical sample with
the completed recovery interval.

Run A proves a real stream/history overlap: one signature was delivered through
each interface. Run B proves nonempty recovery: transaction slot **452823910**
falls strictly within the disconnected interval. It is an account-creation
transaction, not a buy/sell. It was absent from the live capture, present in
`getSignaturesForAddress`, and returned by Parsed Events history after reconnect.
No recovery is claimed for an arbitrary outage or every owned token account.

Total: **27 HTTP requests**, **1 consumed live notification**, **154 estimated
credits** (14 history requests × 10 + 13 RPC requests × 1 + 1 event × 1).
There is no provider dashboard before/after reading. Queued unread stream
deliveries can differ from client consumption; 154 is not an invoice assertion.
Each probe had a 500-credit local budget and bounded time/event/request counts.

The [aggregate result artifact](WO-002-results.json) preserves the reports,
request timestamps, method counts and SHA-256 fingerprints of private evidence.
It contains no wallet addresses, signatures or credentials. Seven committed
[sanitized fixtures](../../tests/fixtures/solana/README.md) preserve reviewed
payload facts, including the recovered transaction.

## Reproduction

Inside the pinned devcontainer, set `HELIUS_API_KEY` privately in `.env` and save
1–3 case-preserved Solana addresses as a JSON array in `watchlist.local.json`.
Both paths are ignored. The key's plan and available credits must be known before
opting in. No signing key is required.

```bash
make fixtures
make test
make lint

# Live calls consume Helius credits; never run these automatically in CI/bootstrap.
uv run --locked --group qualification python scripts/qualify_solana.py --live
uv run --locked --group qualification python scripts/qualify_solana.py \
  --live --seconds 30 --gap-seconds 300 --max-events 100
```

`make qualify-solana` runs the first live command. The optional qualification
dependency group pins `websockets==17.0.1`; the default offline setup does not
need it. The maximum configurable run uses two 150-second windows and a
300-second outage. HTTP calls have separate 30-second timeouts and a bounded
number of pages. A failed run stops rather than retrying indefinitely.

Outputs remain in a new private directory under `local-data/qualification/`.
The script prints only aggregate results and bounded error codes. The watchlist
and request bodies stay private. Review captures before exporting any fixture.

- `make lint test fixtures`: passed; 26 offline tests, all seven real fixtures,
  Ruff, ESLint and Prettier checks. `git diff --check` passed.

  execution-status checks, reviewed owner balance assertions, and shared
  stream/history signature identity checks.

  repeated cursors, empty/incomplete recovery evidence, overlap deduplication,
  exact integer preservation and private evidence file permissions.

  attribution belongs in the commit. Exported fixtures remove encoded data and
  free text as well as direct identifiers.
- A scan of all changed/new tracked candidates found zero matches for the actual
  key or either supplied wallet. Git ignore checks passed for `.env`, the local
  watchlist and the raw capture directory.

These tests establish the qualification tooling and source evidence. Application
ingestion, a production normalizer, durable database checkpoints and alerts are
not implemented by this issue.
